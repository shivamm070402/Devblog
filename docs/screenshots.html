📸 How to Take Screenshots

  1. Open each screenshot HTML file in your browser
  2. Press Ctrl + P (Windows) to open Print dialog
  3. Change "Destination" to "Save as PDF" or "Microsoft Print to PDF"
  4. Click "Save" to save as PDF, or "Print to Image" if available
  5. Upload the saved images to the docs/ folder
